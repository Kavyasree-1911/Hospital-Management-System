# Hospital-Management-System
A Java-based Hospital Management System developed using JDBC and MySQL for managing patients, doctors, and appointment bookings. The project provides functionalities such as adding patients, viewing patient and doctor records, checking doctor availability, and booking appointments through a console-based interface. It demonstrates database connectivity, CRUD operations, and object-oriented programming concepts in Java.

# Hospital Management System

A Java console-based application for managing patients and doctors.

## Features
- Add Patient
- View Patient Details
- Add Doctor
- View Doctor Details

## Run

javac *.java
java HospitalManagementSystem
